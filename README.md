## Run in the background at login

Easiest: double-click `Install Hood Classic Detector.command` (it explains what it will do and asks first). Double-click it again to uninstall. If macOS blocks it, right-click → Open once.

Or from a terminal:

```
./service.sh install     # start now and on every login
./service.sh status
./service.sh logs
./service.sh uninstall
```

The first time it runs, macOS will ask to let Python control Music — click OK.
